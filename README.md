## 🧠 At a glance

| | |
|---|---|
| 🧭 **What** | `helper.py`: functions used by brainlife Apps that process MEG/EEG data |
| 🕰️ **Last change** | 2021-06-25 |

## 🚀 Use it in an App

```bash
git submodule add https://github.com/brainlife/brainlife_apps_helper
```

Then `from brainlife_apps_helper import helper` in the App's Python code.
